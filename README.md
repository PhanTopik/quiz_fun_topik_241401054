Nama Aplikasi: Quiz Fun Topik
Deskripsi singkat Aplikasi:
Pengguna akan dapat mendaftar akun dan mengerjakan quiz-quiz yang ada dalam aplikasi.pengguna juga akan bisa mengejek riwayat nilai dari quiz yang sudah dikerjakan sebelumnya.

Fitur-fitur yang tersedia:
- Daftar Akun
- Ganti Password
- Mengerjakan quiz
- Melihat riwayat pengerjaan quiz sebelumnya
- Ganti nama akun
- Mengaktifkan mode gelap
- Menyimpan jawaban quiz sebelumnya saat mengerjakan quiz selanjutnya
- pencarian nama quiz
